## 2024-10-22 - [Add Strict Content Security Policy]
**Vulnerability:** The application lacks a Content Security Policy (CSP), meaning that if an XSS vulnerability were to be exploited, an attacker could potentially exfiltrate data to an external server. The application is meant to be offline-first and fully local.
**Learning:** The application architecture relies heavily on inline event handlers (e.g., `onclick="app.toggleTask('...')"` in `src/app.js`) and inline styles. Therefore, the standard advice to disable `'unsafe-inline'` for `script-src` and `style-src` would completely break the application's functionality. The primary security objective for this specific architecture is preventing data exfiltration, rather than preventing script execution entirely, which requires `connect-src 'self'`.
**Prevention:** Always implement a baseline CSP that restricts `connect-src` in offline-first applications to mitigate data exfiltration risks. Avoid using inline handlers in future development to allow for stricter `script-src` policies.
