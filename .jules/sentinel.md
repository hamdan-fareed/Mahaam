## 2023-11-02 - Added Content-Security-Policy (CSP) to Electron/Offline App
**Vulnerability:** The application is an Electron-based, offline-first application that handles user-generated input (tasks, notes). It was missing a Content-Security-Policy (CSP) meta tag in its main HTML entry (`src/index.html`), increasing the risk of data exfiltration and external script execution if an XSS vulnerability were to exist.
**Learning:** Even fully offline apps and Electron apps require a strict CSP as an essential layer of defense-in-depth, specifically to restrict connections (`connect-src 'self'`) and external resource loading (`default-src 'self'`). Because the architecture heavily relies on inline event handlers and styles, we must allow `'unsafe-inline'` for scripts and styles, but restricting other origins is critical.
**Prevention:** Always define a Content Security Policy for all web-based architectures, including Electron apps (even when `nodeIntegration` is disabled) and local PWAs. Enforce a strict `connect-src` to ensure data cannot be sent out to arbitrary servers without consent.
